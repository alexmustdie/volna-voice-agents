# Заметки: цены и живые проверки

Вынесено из README: цифры привязаны к датам и устаревают. Технический README на них не опирается.

## Цены

- OpenAI GPT-Live-1: $0.05/мин плюс токены бэкенд-модели (`BACKEND_MODEL`). Тест в браузере
  тарифицируется как обычная сессия.
- Yandex AI Studio Realtime (docs/ai-studio/pricing, 13.09.2026): входящее аудио 0,0264 ₽/с,
  исходящее 0,0203 ₽/с, итого около 2,8 ₽/мин плюс токены 0,1-0,8 ₽/1000.

## Живые проверки

- 13.09.2026, OpenAI GPT-Live-1 (audio/pcm 24000, delegation responses): старт сессии, аудио в обе
  стороны, транскрипты (приходят автоматически фрагментами ~200 мс), usage и закрытие. Модель не
  говорит первой и ждёт реплики абонента. Function calling на живом трафике не проверен: в пробе
  инструменты не вызывались. Документация OpenAI (guides `voice-websockets?api=live`,
  `live-conversations`, `live-delegation`, `voice-sip?api=live`) по состоянию на ту же дату.
- 13.09.2026, Yandex Realtime (speech-realtime-260528, audio/pcm 24000, голос dasha): родная русская
  речь, распознавание клиента, перебивания, function calling (`report_outcome`, `end_call`), несколько
  функций в одном ответе. Подробности протокола в шапке `app/live/yandex_live.py`.
- 19.09.2026: по документации GPT-Live явного события о перебивании нет, сброс очереди Twilio идёт по
  транскрипту речи клиента и порогу `BARGE_IN_CLEAR_SECONDS`.
- 03.10.2026: пол голосов OpenAI измерен по основному тону записей (`app/live/voices.py`).
